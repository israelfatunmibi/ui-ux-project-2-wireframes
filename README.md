# Project 2: The Blueprint (Wireframing)

**UI/UX Design Internship, DecodeLabs (Batch 2026)**
**Author:** Israel Fatunmibi

## Scenario
An e-commerce brand is losing customers during checkout. The layout is cluttered and users are confused. They need a clean, logical structure for their homepage.

## My role
UX designer: design the "skeleton" of the experience, focusing only on user flow and hierarchy.

## Deliverables
1. **Desktop homepage wireframe** (1440px)
2. **Mobile homepage wireframe** (393 x 2368)

## Design decisions
- One primary CTA per section (solid black), with outlined secondary buttons and text links
- Z-pattern for the hero, F-pattern for product grids
- Black, white and grey only; images shown as placeholder boxes
